# Architecture Map: MuJoCo_Models

Architecture map and system boundaries for `MuJoCo_Models` following the Mermaid C4 contract.

## Context View (C4Context)

```mermaid
C4Context
    title System Context Diagram - MuJoCo_Models

    Person(researcher, "Biomechanics Researcher / Engineer", "Designs simulations, evaluates joint torques, and runs musculoskeletal analysis.")
    System_Ext(upstream_drift, "UpstreamDrift", "Athletic movement and biomechanics suite integrating MuJoCo models.")
    System_Ext(mujoco_native, "MuJoCo Physics Engine", "Native physics simulation engine executing generated MJCF XML models.")

    System(mujoco_models, "MuJoCo_Models", "Musculoskeletal MJCF model builders and trajectory optimization helpers for barbell exercises.")

    Rel(researcher, mujoco_models, "Invokes CLI or Python API to generate models", "CLI / Python API")
    Rel(upstream_drift, mujoco_models, "Imports exercise model builders and anthropometrics", "Python Package")
    Rel(mujoco_models, mujoco_native, "Exports valid MJCF XML documents for simulation", "XML / MJCF")
```

## Container View (C4Container)

```mermaid
C4Container
    title Container Diagram - MuJoCo_Models Components

    Container(cli, "CLI Entrypoint", "Python module (__main__.py)", "Provides CLI 'mujoco-models' commands for model generation.")
    Container(exercises, "Exercise Builders", "Python (mujoco_models.exercises)", "Specific model builders: Squat, Bench Press, Deadlift, Snatch, Clean & Jerk, Gait, Sit to Stand.")
    Container(shared_body, "Shared Body Library", "Python (mujoco_models.shared.body)", "Winter 2009 anthropometric tables, axial skeleton, upper and lower limb assemblies.")
    Container(shared_barbell, "Shared Barbell Library", "Python (mujoco_models.shared.barbell)", "IWF/IPF Olympic barbell, weight plates, and weld constraint generation.")
    Container(contracts, "Design by Contract", "Python (mujoco_models.shared.contracts)", "Preconditions and postconditions validating physical and geometric constraints.")
    Container(optimization, "Trajectory Optimizer", "Python (mujoco_models.optimization)", "Balance, bar path, and joint effort cost functions for kinematic trajectories.")
    Container(model_pack, "Model Pack Plugin", "Python (mujoco_models.model_pack)", "Biomech model pack registration and packaging manifest.")

    Rel(cli, exercises, "Configures and runs", "Python")
    Rel(exercises, shared_body, "Assembles musculoskeletal segments", "Python")
    Rel(exercises, shared_barbell, "Attaches barbell and loads", "Python")
    Rel(exercises, contracts, "Enforces input/output validity", "Python")
    Rel(exercises, optimization, "Supplies kinematics for trajectory costs", "Python")
    Rel(model_pack, exercises, "Discovers and registers model builders", "Entry Points")
```
